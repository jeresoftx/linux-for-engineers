# Linux para Ingenieros

Curso de Jeresoft Academy sobre terminal, archivos, procesos, permisos, redes, servicios y automatización pequeña en Linux.

El entorno canónico de laboratorios será Debian dentro de Docker. El curso no solicita privilegios sobre el host ni presenta comandos destructivos como recetas sin contexto. Todo contenido inicia en `draft`.

La fuente de verdad es el [plan versionado](docs/superpowers/plans/2026-07-31-linux-for-engineers-course.md). El trabajo se sigue en el [GitHub Project](https://github.com/users/jeresoftx/projects/26).
